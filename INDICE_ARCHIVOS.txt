💡 CONFIGURACIÓN RECOMENDADA
════════════════════════════════════════════════════════════════════════════════

Para PRINCIPIANTES:
└─ Editar config_robot.py
└─ FRONT_THRESHOLD = 80  (detectar más lejos)
└─ DEFAULT_SPEED = 100   (ir más lento)
└─ DEBUG = True          (ver logs)

Para EXPERTOS:
└─ Ajustar PROFILES['aggressive']
└─ Modificar logic en calculate_navigation()
└─ Añadir sensores adicionales

Para COMPETENCIAS:
└─ FRONT_THRESHOLD = 30
└─ DEFAULT_SPEED = 200
└─ Calibrar servo y motor

✓ Usar Ctrl+C para parar emergencia
✓ LiDAR debe tener línea de visión despejada


📞 AYUDA
════════════════════════════════════════════════════════════════════════════════

Problema: "Permission denied" a /dev/ttyACM0
└─ Solución: sudo usermod -a -G dialout $USER + reiniciar

Problema: LiDAR no se conecta
└─ Solución: ls /dev/ttyUSB* → verificar puerto y editar config

Problema: Arduino no responde
└─ Solución: Verificar que código está cargado + reconectar USB

Problema: Motor no gira
└─ Solución: Verificar conexiones L298N y alimentación 12V
