🎯 FLUJO DE TRABAJO

1. INSTALACIÓN (primera vez)
   ├─ Raspberry Pi: bash setup_elegoo.sh
   ├─ Arduino IDE: Cargar esquiva_lidar_elegoo.ino
   └─ Verificar: python3 prueba_conexiones.py

2. OPERACIÓN NORMAL
   ├─ Raspberry Pi: python3 robot_esquiva_lidar.py
   └─ Robot funciona automáticamente

3. MANTENIMIENTO
   ├─ Calibración: Editar FRONT_THRESHOLD en robot_esquiva_lidar.py
   ├─ Pruebas: python3 control_manual.py
   └─ Debug: Revisar ESQUEMA_CONEXIONES.txt

📞 SOPORTE RÁPIDO

Problema                    Solución
─────────────────────────────────────────────────────────────────────
Arduino no se conecta       ls /dev/ttyACM*
LiDAR no se conecta         ls /dev/ttyUSB*
Permission denied           sudo usermod -a -G dialout $USER
Motores no funcionan        Revisar conexiones L298N
Servo no responde           Verificar pin 10
Cambiar velocidad robot     Editar MOTOR_NORMAL en robot_esquiva_lidar.py
